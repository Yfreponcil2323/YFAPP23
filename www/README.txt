YF REPONCIL - VERSI MOBILE LENGKAP
=================================

Model harga:
- SATU harga yang tampil adalah harga final.
- Harga sudah termasuk sparepart + jasa pasang.
- Tidak ada kolom jasa terpisah dan tidak ada perhitungan harga + jasa.

Fitur:
- Login private: Yfreponcil / Yfreponcil23
- Beranda dengan slideshow 6 gambar: LCD1, LCD2, LCD3, BATERAI1, BATERAI2, BATERAI3
- Slideshow otomatis dan bisa swipe di HP tanpa tombol panah.
- Ukuran gambar mengikuti rasio asli setiap gambar agar tidak terpotong atau melebar.
- Navigasi Beranda / LCD / Baterai / Pengaturan.
- Pencarian LCD dan baterai.
- Pengaturan > Edit Harga: ubah harga final dan kualitas.
- Pengaturan > Edit Tipe HP: ubah tipe HP/merek.
- Pengaturan > Tambahkan Data: tambah data baru dengan harga final all-in.
- Pengaturan > Backup & Restore: simpan/pulihkan perubahan dalam JSON.
- Data perubahan tersimpan di perangkat/browser melalui localStorage.
- Mode aplikasi portrait dan tidak bisa di-zoom.

Cara pakai:
1. Buka index.html atau pasang folder ini sebagai web/PWA.
2. Login dengan akun di atas.
3. Pilih LCD atau Baterai dari menu bawah.
4. Cari tipe HP untuk melihat harga final.
5. Untuk mengubah data, buka Pengaturan.
6. Selalu lakukan Backup JSON sebelum memindahkan/reset perangkat.

Catatan:
- Login ini adalah gate frontend untuk pemakaian pribadi, bukan sistem keamanan server.
- Data edit/tambah hanya tersimpan di browser/perangkat sampai di-backup.
